Privacy Policy

Who we are

This is the personal course site of Abdul Hadi M. Alaidi, lecturer at Wasit University. Its address is https://alaidi.net. Questions about this policy can be sent through the contact details on the About me page.

What this site is

alaidi.net is a static site: a set of HTML pages and lecture files served as they are. There are no accounts, no logins, no comments, no contact forms and no uploads. Nothing you do here is stored on the server beyond the ordinary request logs described below.

Analytics

This site uses Rybbit, a privacy-focused analytics tool, running on our own server at analytics.iq-server.com. It is there to show which course pages and lecture files are actually being used. It does not set any cookies, and the data is not sold, shared or used for advertising.

For each page you view it records:

  • the page address, its title and the referring page, if any;
  • your screen size and browser language;
  • your IP address and browser user agent string, which every web server receives, used to work out the approximate country and the browser and device family.

It also stores one value in your browser’s local storage, rybbit-visitor-id: a random string with no connection to your identity, used to tell repeat visits apart. It stays until you clear your browser storage for this site.

How to opt out

Any tracking blocker will stop the script. To switch it off for this site only, open your browser’s developer console on any page here and run localStorage.setItem("disable-rybbit", "1") — the script then loads but does nothing. Running localStorage.removeItem("disable-rybbit") turns it back on.

Cookies and local storage

This site sets no cookies. It stores two values in your browser’s local storage to remember how you like the site to look — theme (light or dark) and view (cards or table on the home page) — plus the analytics identifier described above. None of it leaves your browser except that identifier, and clearing your browser storage removes all three.

Other third parties

Fonts, images, stylesheets and lecture files are all served from this site — no font CDN, no embedded videos, no social widgets. Some pages link out to other sites, such as Wasit University, YouTube or GitHub. Those links are ordinary links: nothing is loaded from them until you click, and once you do, that site’s own privacy policy applies.

Server logs

The web host keeps standard access logs, which include IP addresses, for security and troubleshooting. They are kept for a limited period under the host’s own retention policy and are not used to build visitor profiles.

How long data is kept

Analytics data is retained in aggregate for as long as the site runs. It contains no names, email addresses or accounts, so there is no personal profile to export or delete — clearing your browser storage removes the only identifier tied to your visits.

Changes to this policy

This policy was last updated on 16 September 2026. It will be updated here if the site starts collecting anything else.
